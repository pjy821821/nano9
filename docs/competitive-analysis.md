# 경쟁 분석: 블록 퍼즐로 월 100만 원이 가능한가

작성일: 2026-11-02
전제: 1인 개발, 광고 집행 예산 없음, 세로 화면 싱글 플레이, 목표 월 100만 원(약 700달러)

## 1. 한 줄 결론

**똑같이 만들면 묻힙니다. 그러나 장르를 바꿀 필요는 없습니다.** 블록 퍼즐은 설치 수가 가장 많이 늘고 있는 서브장르이지만 동시에 가장 복제가 많고 매출 규모가 가장 작은 서브장르입니다. 월 100만 원은 "눈에 띄는 한 가지 차별점 + 한국 등 특정 시장 집중 + 2~3개 변형 출시"의 조합일 때 현실적인 목표이고, 단일 복제작으로는 달성 확률이 낮습니다.

## 2. 경쟁 환경 수치

| 항목 | 수치 | 의미 |
|---|---|---|
| Block Blast 2025년 다운로드 | 약 3억 건, 전 세계 모든 모바일 게임 중 1위 | 장르의 검색 수요는 이 한 게임이 만들고 있음 |
| Block Blast 일 광고 매출 추정 | 58만~100만 달러 | 블록 퍼즐은 광고만으로도 돈이 되는 장르 |
| Block Blast 한국 순위 | 2025년 10월 주간 활성 이용자 4위, 매출 순위 100위 밖 | 한국 유저가 많이 하지만 결제는 안 함. 광고 모델이 맞음 |
| 2025년 상반기 신규 블록 퍼즐 출시 수 | 1,000개 이상 | 반년에 1,000개. 하루 5~6개씩 나옴 |
| 블록 서브장르 2025년 매출 | 약 1억 8,300만 달러, 퍼즐 서브장르 중 최하위 | 파이 자체가 작음 |
| 그 매출의 집중도 | Color Block Jam 한 게임이 약 75% | 나머지 1,000여 개가 25%를 나눠 가짐 |
| 3세대 블록 퍼즐(Car Jam 등) 다운로드 | 2025년 감소세 | 유행 교체가 빠름 |

## 3. 솔직한 리스크 평가

**리스크 1. 검색에 묻힘.** "block puzzle" 키워드는 난이도 상(50~70점대)으로 분류됩니다. 같은 키워드를 노리는 거의 동일한 게임이 수백 개면 신규 앱은 순위권에 들지 못합니다. 아이콘과 스크린샷이 Block Blast와 비슷하면 유저 입장에서는 고를 이유가 없습니다.

**리스크 2. 법적 리스크.** Block Blast 개발사는 복제작을 상대로 승소했습니다. 판결 기준은 게임 규칙이 아니라 "보이는 모습과 소리"였습니다. 규칙은 저작권 보호를 받지 않지만, 색상 조합, 타일 모양, 효과음, UI 배치를 그대로 따라가면 문제가 될 수 있습니다. 지금 프로토타입은 자체 제작 색상과 합성 효과음이라 안전하지만, 앞으로도 Block Blast 화면을 참고해 "비슷하게" 만드는 방향은 피해야 합니다.

**리스크 3. 수익 파이가 작음.** 블록 서브장르 전체 매출이 머지 서브장르의 8분의 1 수준입니다. 다만 목표가 월 700달러이므로 전체 파이 크기보다 "DAU 700명을 어떻게 모으느냐"가 문제입니다.

## 4. 그럼에도 블록 퍼즐을 유지하는 이유

- 설치 수 증가율이 서브장르 중 1위(+71%)입니다. 수요는 계속 늘고 있습니다.
- 한국에서 Block Blast가 주간 활성 이용자 4위입니다. 한국 유저가 이 장르를 좋아한다는 검증된 신호입니다.
- 레벨 제작이 필요 없어 1인 개발 범위 안에 있습니다. 머지나 매치3로 가면 콘텐츠 제작에서 승부가 안 됩니다.
- 성공한 후발작들의 공통점은 "규칙은 익숙하게, 보이는 것은 뚜렷하게"였습니다. 이는 1인 개발로도 가능한 차별화 축입니다.

## 5. 차별화 전략 제안

업계 분석의 공통 결론은 "핵심 규칙은 유지하고, 명확한 비주얼 테마 하나와 새 규칙 하나로 구분한다"입니다. 아래 세 안 중 하나를 고르면 됩니다.

### A안. 테마 집중: 한국적 소재 (추천)

- 블록을 떡, 전통 문양, 한글 자모 등 한국 소재로 바꾸고, 줄 제거 시 그 소재에 맞는 연출을 넣습니다.
- Block Blast 복제작이 수백 개여도 "한국 테마 블록 퍼즐"은 거의 없습니다. 국내 검색에서 아이콘만으로 구분됩니다.
- 한국은 보상형 광고 단가가 세계 2~3위권이라 DAU 700명이 모두 국내 유저여도 목표 수익이 나옵니다.
- 리스크: 해외 확장 시 테마가 낯설 수 있음. 영어권용 스킨을 2번째 변형으로 만들면 해결됩니다.

### B안. 규칙 하나 추가: 제한된 회전 아이템

- 대표님이 처음 물어보신 회전을 "1판 3회, 추가는 광고" 아이템으로 넣습니다.
- 수익 지점이 하나 늘고, "회전되는 블록 퍼즐"이라는 검색 키워드를 선점합니다. 실제로 "Block Blast: Rotate Puzzle"처럼 회전을 전면에 내세운 후발작이 있습니다.
- 리스크: 난이도 설계를 다시 잡아야 하고, 이미 같은 키워드를 쓰는 앱이 있습니다.

### C안. 모드 추가: 데일리 챌린지

- 매일 같은 조각 순서가 모든 유저에게 주어지고, 그날의 순위를 보여줍니다. 워들(Wordle)식 설계입니다.
- 리텐션을 올리는 효과가 가장 확실하고, 광고 노출 빈도도 자연스럽게 늘어납니다.
- 리스크: 서버 없이도 가능하지만(날짜 기반 시드), 순위표를 넣으려면 서버가 필요합니다.

**추천 조합: A안을 기본으로 하고, C안을 출시 1개월 뒤 업데이트로 넣는 것.** B안은 플레이 테스트 반응을 보고 결정합니다.

## 6. 마케팅 전략: 광고비 없이 DAU 700명

1. **키워드는 넓은 것보다 좁은 것.** "퍼즐 게임"이 아니라 "블록 퍼즐 한국", "떡 퍼즐", "두뇌 게임 오프라인" 같은 조합을 노립니다. 앱 제목은 "브랜드명 - 장르 설명" 형식이 검색 가중치가 가장 높습니다.
2. **한국 먼저, 그다음 경쟁이 낮은 시장.** 영어권은 경쟁이 가장 심합니다. 브라질, 인도네시아, 터키는 유저는 많고 키워드 경쟁은 낮다는 분석이 있습니다. 광고 단가는 낮지만 설치 수를 확보하는 데 유리합니다.
3. **오프라인 플레이와 적은 광고를 전면에.** 유저 리뷰에서 블록 퍼즐의 가장 큰 불만은 광고 과다입니다. "광고는 선택형 위주, 오프라인 가능"을 스토어 설명 첫 줄에 넣으면 리뷰 평점에서 차이가 납니다.
4. **같은 코드로 변형 2~3개.** 테마 스킨만 다른 앱을 따로 출시해 서로 교차 홍보합니다. 1인 개발 성공 사례의 공통 패턴입니다.

## 7. 현재 프로토타입 상태 평가

| 항목 | 상태 | 비고 |
|---|---|---|
| 핵심 규칙 | 완성 | 8x8, 3조각, 줄 제거, 콤보 |
| 입력 반응성 | 수정 완료 | 컨테이너 히트 영역 원점 버그로 터치 영역이 좌상단으로 밀려 있었음. 슬롯 전체 크기로 확대 |
| 줄 제거 연출 | 강화 완료 | 파동 순서 흰색 플래시, 파편 파티클, 화면 플래시, 흔들림, 점수 팝업, 저음 타격음 |
| 차별화 | 없음 | 위 5장에서 선택 필요. 현재는 일반 블록 퍼즐 |
| 법적 안전성 | 양호 | 자체 색상, 합성 효과음, 자체 UI |
