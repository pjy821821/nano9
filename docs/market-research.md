# 시장조사: 세로 화면 싱글 플레이 모바일 게임, 월 100만 원 목표

작성일: 2026-11-02
조건: 세로 화면, 싱글 플레이, 1인 개발, 태블릿 + 클라우드 세션 환경, 목표 월 수익 100만 원(약 700달러)

## 1. 결론: 하이브리드 캐주얼 블록 퍼즐

추천 장르는 **블록 퍼즐(Block Puzzle)** 입니다. 8x8 격자에 조각을 끌어다 놓고 줄을 지우는 방식으로, Block Blast 계열이 대표작입니다.

추천 이유 세 가지:

1. **성장 중인 서브장르.** 2025년 상반기 블록 퍼즐 설치 수는 전년 대비 71% 증가했습니다. 같은 기간 스크류 퍼즐은 27%, 정렬(Sort) 퍼즐은 14% 늘었습니다. 2026년 상반기 자료에서는 하이브리드 캐주얼 퍼즐이 매치3와 머지2에서 신규 유저를 뺏어오고 있다고 보고됐습니다.
2. **1인 개발 규모에 맞는 콘텐츠량.** 매치3는 수천 개 레벨과 라이브옵스 팀이 필요합니다. 머지2는 Gossip Harbor 중심으로 시장이 빠르게 집중되고 있습니다. 블록 퍼즐은 레벨 제작 없이 무한 모드 하나로 서비스가 가능합니다.
3. **광고 수익화와 궁합이 좋음.** 세션이 길고 플레이 횟수가 많아 전면 광고 노출 지점이 많고, "광고 보고 이어하기"는 가장 전환율 높은 보상형 광고 지점입니다. 한국과 미국은 보상형 광고 단가가 세계 1~3위권입니다.

## 2. 시장 데이터 요약

### 장르별 흐름 (글로벌, 2025년)

| 항목 | 수치 | 비고 |
|---|---|---|
| 퍼즐 장르 인앱 매출 | 82억 달러 이상, 전년 대비 +7.6% | 캐주얼 중 유일하게 성장한 상위 장르 |
| 머지 서브장르 매출 | 약 14억 달러, +80% | 성장 빠르나 상위 몇 개 게임에 집중 |
| 하이브리드 캐주얼 인앱 매출 | 42억 달러, +20% | 2026년 상반기도 +23% |
| 전체 모바일 게임 인앱 매출 | 2026년 상반기 -2%, 다운로드 -12% | 시장 전체는 정체 |
| 블록 퍼즐 설치 수 | 2025년 상반기 +71% | 스크류 +27%, 정렬 +14% |

출처마다 수치 편차가 큽니다. 실제 값은 출시 후 광고 네트워크 대시보드에서 확인해야 합니다.

## 3. 월 100만 원 달성 계산

보상형과 전면 광고를 섞은 혼합 eCPM을 보수적으로 8달러로 잡습니다.

| 단계 | 값 |
|---|---|
| 목표 월 수익 | 700달러 |
| 필요 월 노출 수 | 87,500회 |
| 필요 일 노출 수 | 약 2,900회 |
| 유저 1인당 일 광고 노출 | 4회 가정 |
| **필요 일간 활성 유저(DAU)** | **약 730명** |

DAU 730명은 1인 개발 블록 퍼즐로 현실적인 목표입니다. 다만 아래 통계를 함께 봐야 합니다.

- 앱의 약 83%가 월 1,000달러 미만을 법니다. 광고만으로 운영하는 1인 개발 게임은 안정기에 하루 3~30달러가 일반적인 추정치입니다.
- 월 1,000달러를 넘기는 경우 보통 12~18개월이 걸립니다.
- 그래서 목표 달성 확률을 높이려면 **한 게임에 올인하지 말고 같은 코드베이스로 2~3개 변형(색 맞추기 모드, 시간제한 모드, 테마 스킨)을 출시**하는 전략이 유효합니다.

## 4. 피해야 할 장르와 이유

| 장르 | 피하는 이유 |
|---|---|
| 매치3 | Royal Match 등 대형사 독점. 수천 레벨 제작 필요. |
| 머지2 | 매출 성장은 크지만 상위 소수에 집중. 라이브옵스 비용 큼. |
| 카지노 | 매출 2위 장르지만 국가별 규제, 스토어 심사 리스크. |
| RPG, 전략 | 한국 매출 48%를 차지하지만 팀 단위 개발과 마케팅비 필수. |
| 순수 하이퍼캐주얼 | 2023년 이후 광고 단가 하락으로 UA 비용 회수 어려움. |

## 5. 수익화 설계 (프로토타입에 반영됨)

| 지점 | 형식 | 구현 상태 |
|---|---|---|
| 게임오버 시 이어하기 | 보상형 영상, 1판 1회 | `src/scenes/GameScene.js`에 구현, 광고는 스텁 |
| 3판마다 재시작 시 | 전면 광고 | 구현, 광고는 스텁 |
| 되돌리기(Undo) | 보상형 영상, 1판 1회 | 구현, 광고는 스텁 |
| 아이템 충전 (회전/뒤섞기/새 조각) | 보상형 영상, 소진 시 | 구현, 광고는 스텁 |
| 광고 제거 | 인앱 결제 2,900~4,900원 | 다음 단계 |
| 테마 스킨 | 인앱 결제 또는 보상형 영상 해금 | 다음 단계 |

광고 호출은 모두 `src/ads.js` 한 곳을 거칩니다. Capacitor로 앱을 만들 때 이 파일만 AdMob 또는 AppLovin MAX 플러그인으로 바꾸면 됩니다.

## 6. 다음 단계 로드맵

1. **1~2주차**: 프로토타입 완성도 올리기. 효과음, 햅틱, 콤보 연출, 되돌리기 1회, 튜토리얼 손가락 표시.
2. **3주차**: Capacitor로 안드로이드 APK 빌드. AdMob 연동. Google Play 내부 테스트.
3. **4주차**: 한국과 영어권 동시 출시. 스토어 스크린샷은 세로 5장. 키워드는 "블록 퍼즐", "block puzzle", "브레인 게임".
4. **출시 후 1개월**: 리텐션(D1 35% 이상, D7 10% 이상 목표)과 유저당 광고 노출 수 확인. 전면 광고 빈도 조정.
5. **2~3개월**: 두 번째 변형(시간제한 모드 또는 컬러 매칭 모드)을 같은 코드로 출시해 트래픽 교차 유도.
