# 조각보 (Jogakbo)

한국 조각보를 테마로 한 세로 화면 싱글 플레이 블록 퍼즐입니다. 한지 바탕 위 쪽빛 비단 틀에 색동 천 조각을 붙여 줄을 완성하면 "한 땀, 두 땀" 하고 지워집니다. Phaser 3로 만들었고 빌드 과정 없이 정적 파일로 실행되며, 이미지 파일 없이 모든 그래픽을 코드로 그립니다.

장르 선정 근거와 수익 목표 계산은 [docs/market-research.md](docs/market-research.md)에, 경쟁 환경과 차별화 전략은 [docs/competitive-analysis.md](docs/competitive-analysis.md)에, AdMob 연동 절차는 [docs/admob-integration.md](docs/admob-integration.md)에 있습니다.

## 실행

```bash
npm start        # http://localhost:8080 에서 실행
npm test         # 보드 로직 단위 테스트
```

태블릿에서 바로 플레이하려면 GitHub 저장소 Settings > Pages에서 이 브랜치의 루트(/)를 배포 소스로 지정하면 됩니다.

## 모드와 기록

- **무한 모드**: 조각이 무작위로 나옵니다. 상위 10개 기록을 기기에 보관합니다.
- **오늘의 조각보**: 날짜를 시드로 써서 같은 날이면 누구에게나 같은 조각 순서가 나옵니다. 날짜별 최고 점수를 보관하고 최근 7일을 보여줍니다. 서버 없이 동작합니다.
- **공유하기**: 게임오버 화면에서 점수와 최고 연속 배율을 기기 공유 시트로 보내고, 안 되면 클립보드에 복사합니다.
- 기록은 모두 `localStorage`에만 저장됩니다. Play 게임즈 리더보드(출시 시)와 서버 순위판(유저 확보 후)은 다음 단계입니다.

## 조작

- 아래 3개 조각 중 하나를 끌어 보드에 놓습니다. 무한 모드는 쓴 자리가 바로 채워지고, 오늘의 조각보는 3개를 다 써야 채워집니다(장르 표준, 긴장감 높음). `src/config.js`의 `REFILL_MODE`에서 모드별로 바꿀 수 있습니다.
- 가로 또는 세로 한 줄이 가득 차면 "한 땀!" 하고 지워집니다. 동시에 2줄 이상이면 "두 땀!!" 콤보 보너스.
- 놓을 자리가 없으면 게임오버. 광고 보고 이어하기(1회) 또는 다시 시작.
- 왼쪽 위 ↶ 버튼: 광고 보고 마지막 수 되돌리기(1판 1회). 오른쪽 위: 음소거.
- **연속 제거**: 줄을 지운 직후 다음 조각으로도 지우면 배율이 ×2, ×3... 최대 ×5까지 오릅니다. 못 지우면 끊깁니다.
- **아이템** (보드 아래 버튼, 다 쓰면 광고로 충전):
  - 회전 (1판 3회): 대기열 조각을 짧게 톡 치면 시계 방향으로 90도 돕니다.
  - 뒤섞기 (1판 1회): 보드에 붙은 조각 전체를 무작위 자리로 다시 놓습니다.
  - 새 조각 (1판 1회): 대기열 조각 3개를 새로 뽑습니다.
- 게임오버 후 "광고 보고 이어 짓기"는 대기열 조각 중 하나가 반드시 들어갈 수 있을 때까지 칸을 비웁니다.
- 첫 실행 시 손가락 애니메이션으로 조작법을 안내합니다.

## 구조

| 경로 | 역할 |
|---|---|
| `index.html` | 진입점. 세로 고정, 확대 방지 |
| `src/config.js` | 보드 크기, 셀 크기, 조각보 색상 팔레트, 폰트, 점수 규칙 |
| `src/art.js` | 한지 텍스처, 천 조각 셀, 색동 띠 보드 틀, 낙관 도장 드로잉 |
| `src/shapes.js` | 조각 모양 27종 |
| `src/board.js` | 순수 게임 로직 (렌더링과 분리, 테스트 대상) |
| `src/ads.js` | 광고 추상화. 현재는 스텁, 앱 포장 시 교체 |
| `src/rng.js` | 시드 난수(mulberry32)와 날짜 키. 오늘의 조각보 모드용 |
| `src/records.js` | 내 기록 보관(무한 상위 10, 날짜별 데일리 최고) |
| `src/scenes/MenuScene.js` | 시작 화면: 모드 선택, 내 기록 |
| `src/audio.js` | Web Audio 합성 효과음(국악 5음계, 목탁 톡 소리)과 햅틱 |
| `src/scenes/GameScene.js` | 렌더링, 드래그 입력, 게임오버 UI |
| `vendor/phaser.min.js` | Phaser 3.87.0 (오프라인 실행용) |
| `tests/` | Node 내장 테스트 러너 사용 |
